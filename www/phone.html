Step 1 · Trust the certificateLangkah 1 · Percaya sijil

Dashboard Cuaca Aziz has its own certificate, "Dashboard Cuaca Local CA". It is only for the connection between your phone and your PC.Dashboard Cuaca Aziz ada sijil sendiri, "Dashboard Cuaca Local CA". Ia hanya untuk sambungan antara telefon dan PC anda.

Download certificateMuat turun sijil
  1. Tap Download certificate above, then Allow.
  2. Open Settings → Profile Downloaded (at the top) → Install → passcode → Install.
  3. Do not skip: Settings → General → About → Certificate Trust Settings → turn ON Dashboard Cuaca Local CA → Continue.

Step 2 · Open Dashboard Cuaca AzizLangkah 2 · Buka Dashboard Cuaca Aziz

Open Dashboard Cuaca AzizBuka Dashboard Cuaca Aziz
  1. The address must open with no warning. A red "Not secure" warning means step 1 is not finished.
  2. Install: iPhone / iPad → Share → Add to Home Screen. Android → Install app.
  3. For notifications: open the app → Settings → Notifications on this phone → Allow.

  2. Pasang: iPhone / iPad → Share → Add to Home Screen. Android → Install app.
  3. Untuk notifikasi: buka app → Tetapan → Notifikasi di telefon ini → Benarkan.
